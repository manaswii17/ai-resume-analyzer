# AI Resume Analyzer & Job Matching System

An NLP-based application that analyzes resumes against job descriptions and provides resume-job matching insights.

## Tech Stack

- Python
- NLP
- NLTK
- spaCy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit
- PyPDF2
- Pandas
